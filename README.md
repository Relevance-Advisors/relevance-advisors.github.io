# relevance-advisors.github.io

Sable & Rye Bakehouse, the fictional bakery used as the Relevance Audits demo and test site, served at
https://relevance-advisors.github.io/ . A root-path copy of
[relevance-audit-test-site](https://github.com/Relevance-Advisors/relevance-audit-test-site) (which stays at
its project-site URL with its own Search Console property): the audit crawls a client's domain from its
root, so the demo client needs the site at the root of a host.
